# Organisation du projet

- Type : projet
- Nom canonique : Scrypted
- Dépôt principal : `.` (`Recoveredd/scrypted`, fork de `koush/scrypted`)

Les dépôts imbriqués déclarés comme sous-modules sont des dépendances externes du projet. La dépendance `external/ring-client-api` pointe vers `Recoveredd/ring` afin de conserver et reproduire le correctif des comptes partagés.
